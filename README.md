# BMW-Car-Sales-Dashboard
BMW Car Sales Dataset (2010–2024) Contains 50,000 rows detailing BMW sales across regions and series. Includes model, year, region, color, fuel type, transmission, engine size, mileage, price, sales volume, and classification. Useful for trend analysis and market insights.
# BMW Car Sales Analysis (2010–2024)

This repository contains a **BMW car sales dataset** spanning **2010 to 2024**, covering multiple regions, BMW series, and key vehicle attributes. It provides a comprehensive view of sales trends, market distribution, and consumer preferences over more than a decade.

## Dataset Description
- **Rows:** 50,000  
- **Columns:** 11  

### Variables
| Column Name           | Description                                                                 |
|-----------------------|-----------------------------------------------------------------------------|
| Model                 | BMW model sold, including various series                                    |
| Year                  | Year of purchase                                                            |
| Region                | Region of sale (Africa, Europe, North America, Middle East, South America, Asia) |
| Color                 | Vehicle color (Black, Blue, Red, Grey, Silver, White)                       |
| Fuel_Type             | Petrol, Hybrid, Electric, Diesel                                            |
| Transmission          | Automatic or Manual                                                         |
| Engine_Size_L         | Engine capacity in liters (1.9–5.0L)                                        |
| Mileage_KM            | Vehicle mileage in kilometers                                              |
| Price_USD             | Selling price in USD                                                        |
| Sales_Volume          | Number of units sold                                                       |
| Sales_Classification  | "High" or "Low" based on sales volume                                       |

## Key Insights
- **SUV Reign:** X Series leads global sales with over 18,000 units.  
- **Engine Size & Buyer Behavior:** Cars with large engines (3.0–5.0L) top sales; I Series shows growing electric adoption.  
- **Transmission vs Fuel Type:** Manual transmissions slightly lead overall, showing regional preferences.  
- **Price Consistency:** BMW maintains an average price of ~$75,000 across regions.
